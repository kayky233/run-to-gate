# Notice

`run-to-gate` is an original, platform-neutral orchestration skill.

Its decision-mapping vocabulary and selected engineering disciplines are inspired by Matt Pocock's public `mattpocock/skills` collection, including Wayfinder-style destination/fog/frontier mapping, tracer-bullet ticketing, test-driven development, diagnosis loops, and two-axis code review. That upstream repository is MIT licensed.

The optional `rtg-*` companion skills in this bundle are purpose-built adapters for this distribution; they are not presented as verbatim upstream skills. No external skill is required at runtime because the main skill includes equivalent built-in reference branches.
